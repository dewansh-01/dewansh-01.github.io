SQL-Agent

Multi-agent text-to-SQL

Stable Cohorts

Segmentation that survives a reseed

Finds customer cohorts in transactional data by sweeping K-Means, GMM and HDBSCAN across feature sets, then keeps the configuration that holds up out of sample — bootstrap resampling scored by the Adjusted Rand Index — so the segments are reproducible, not an artefact of one random seed.

06

Triage Graph

Role-aware healthcare GraphRAG

In progress

A GraphRAG system built the way a hospital deployment would need it. Doctors, staff and pharmacists each see only their slice of the graph, and that rule is enforced in the retrieval query itself, not left to the prompt. Retrieval depth is chosen per question rather than fixed, and an evaluation pipeline will compare it against fixed-K and measure leakage across roles. All data is synthetic or public: Synthea patients, openFDA labels, RxNorm and DDInter interactions.

GraphRAG / Claude / Synthea / openFDA / RxNorm / Python
